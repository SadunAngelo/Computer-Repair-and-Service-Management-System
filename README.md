# 🛠️ Computer Repair and Service Management System

A full-stack web application designed for computer repair shops, allowing customers to submit repair requests and track their status in real-time, while providing technicians with an admin dashboard to log parts, manage repair progress, and calculate cost/time estimates.

> 🚧 **Status:** Active Development (Ongoing)

## 🌟 Key Features
* **Customer Portal:** Submit computer repair requests and monitor real-time repair status updates.
* **Technician & Admin Dashboard:** Update job status, log replacement parts, and manage labor/cost estimates.
* **Role-Based Access Control (RBAC):** Secure authentication segregating permissions and views between customers and staff.

## 🛠️ Tech Stack
* **Frontend:** React, HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** Role-Based Access Control (RBAC) & JWT
